### 2.2.2 - Mathematical Formalization

There are several formalizations I've seen of this algorithm. Some resources make use of a diffusion operator, whereas others may utilize an oracle. I will attempt to explain this algorithm in many different contexts, so that you are able to recognize it in any of them.

As always, my [[#^a6c83c|resources]] are linked at the bottom of the page.

#### "The Problem"
We are tasked with searching through a space of $N$ elements, just as in the classical counterpart for this problem. Here, we will select $N$ such that $N=2^n$, so that the index to the elements can be stored in $n$ bits. There are $M$ solutions to this problem (where $1\leq M\leq N$).

#### Grover's Algorithm With A Quantum Oracle

The quantum search algorithm (Grover's Algorithm) consists of *repeated applications of the **Grover Operator** $G$*. This is sometimes referred to as a **quantum subroutine**, known as the Grover iteration. This iteration has the following four steps, which will be explained in detail immediately afterwards:
1. Apply the **oracle** $O$
2. Apply the **Hadamard transform** $H^{\otimes n}$ 
3. Perform a conditional phase shift on the computer, with every computational basis state except $|0\rangle$ receiving a phase shift of $-1$.
4. Apply the Hadamard transform again.

#### Step 1: The Oracle

I will first define a function $f(x)$ where $x\in \mathbb{Z}$ such that $f(x)=1$ if $x$ is a solution to the search problem and $f(x)=0$ if $x$ is not a solution.

The **Quantum Oracle** is a unitary operator $O$ (sometimes denoted as $U_f$ or something of that nature) which flips an **oracle qubit** $|q\rangle$ if $x$ is a solution and leaves it unchanged if not:
$$
|x\rangle |q\rangle \xrightarrow{O} |x\rangle |q\oplus f(x)\rangle
$$
Here, $|x\rangle$ denotes the **index register** and $\oplus$ denotes addition modulo 2. This conventional oracle, given more explicitly as 
$$
U_{f}*|x\rangle \otimes |y\rangle = |x\rangle \otimes|y\otimes f(x)\rangle
$$
can be turned into a **phase oracle** by utilizing a $|-\rangle$ [^1]**ancilla** and a phase kickback. Several sources of mine cited a similarity in this method to the **Deutsch-Jozsa Algorithm**, so I will dedicate an entry to this later as well. 

Employing this method, we make one simple change. Instead of preparing, say $|x\rangle |0\rangle$ or $|x\rangle |1\rangle$ and then applying the oracle to see if it flips to $|1\rangle$ or $|0\rangle$ respectively, we will prepare the oracle qubit as:
$$
|x\rangle \frac{{|0\rangle -|1\rangle}}{\sqrt{ 2 }}
$$
Just as before, if $x$ is not a solution, applying the oracle to the state above does nothing. But if it is a solution, $|0\rangle$ and $|1\rangle$ are swapped, which yields
$$
|x\rangle \frac{{|1\rangle-|0\rangle}}{\sqrt{ 2 }}=-|x\rangle \frac{{|0\rangle - |1\rangle}}{\sqrt{ 2 }}
$$
Which simply flips the sign of the initial state (or rather, shifts the phase). Because the state of the oracle qubit $|q\rangle$ itself is invariant, it may be omitted, and the action of the phase oracle may be formalized elegantly as:
$$
|x\rangle \xrightarrow{O} (-1)^{f(x)}|x\rangle
$$
