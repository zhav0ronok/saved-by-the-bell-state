I'm bored, so I decided I'll make an operating system.

The first step for me, of course, is to read through Linux From Scratch (LFS). The book is downloadable from the official LFS website, and I will link it in the [[LFS#^ee81e8|resources]] section at the bottom of this page.

LFS systems are built by using an already installed Linux distribution (this system is called the host) as a starting point to build the new system. I will likely be doing this in a virtual machine on either my spare Windows laptop or my PC, as I don't have a computer available to fully sacrifice for a few days. According to Chapter 2 of LFS, the editors suggest that the system CPU have:
- At least four cores
- At least 8GB of memory
so that package build times are within reason.

Other host system requirements are listed in section 2.2.2 of LFS.
