#### Getting Started With Qiskit

Qiskit is an open source, python based software stack developed by IBM for quantum computing (QC). It is a wonderful tool for learning about QC, and I would highly suggest experimenting with it in your editor of choice. 

I am using neovim (with LazyVim) on Linux, so the [[Qiskit Setup Guide For LazyVim|setup guide]] I wrote will of course be tailored to that, as I cannot speak for much else. If you are using a different editor or OS, please refer to the [official documentation](https://github.com/Qiskit/qiskit).
